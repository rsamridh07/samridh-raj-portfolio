SAMRIDH RAJ — NEON ROBOTICS PORTFOLIO

This is a responsive static portfolio website inspired by the exact dashboard layout supplied by Samridh.

HOW TO PREVIEW
1. Extract the ZIP file.
2. Open the Samridh-Premium-Portfolio folder.
3. Double-click index.html (or open it with Chrome/Edge).

HOW TO PUBLISH ON GITHUB PAGES
1. Create a GitHub repository (for example: samridh-raj-portfolio).
2. Upload index.html, style.css, script.js, README.txt and the complete assets folder.
3. Open repository Settings → Pages.
4. Select Deploy from a branch → main → /(root) → Save.
5. Wait for GitHub Pages to publish your website.

PERSONALISE BEFORE PUBLISHING
- Replace the generic social profile links in index.html with your real LinkedIn, GitHub, Instagram and YouTube profile URLs.
- Add any additional original certificate scans to the assets folder and update the image paths in index.html.
- The BIS and Speech thumbnails are cropped from the supplied portfolio reference image because separate original scans were not available in the supplied files.
- The Fire Fighting Robot is labelled as a concept, not a confirmed completed project.

The site uses local image assets and Google Fonts (internet connection is needed for the fonts; the page still works without them).
